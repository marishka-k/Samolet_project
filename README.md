# Самолёт — карточки для разговора

Одностраничный сайт-игра по собственному макету в Figma «Samolet — Digital Cards»:
вопросы-карточки, которые помогают разговориться с партнёром, друзьями, семьёй или коллегами.

**Сайт:** https://marishka-k.github.io/Samolet_project/

React 18 · Vite 5 · CSS Modules

## Как работает игра

- Четыре категории — для пары, друзей, семьи и коллег, — в каждой по 200 вопросов (`src/data/questions.js`).
- Колода — 10 случайных вопросов выбранной категории (`DECK_SIZE` в `src/utils/deck.js`).
- Клик по обложке переворачивает верхнюю карточку, «Следующий вопрос» открывает следующую.
  Под верхней карточкой видна стопка оставшихся.
- На последней карточке — «последний вопрос» и кнопка **«Начать игру заново»**: новая колода
  той же категории из вопросов, которые ещё не выпадали. Когда новых меньше 10, круг начинается заново.
- Вопросом можно поделиться: системное меню «Поделиться» или копирование в буфер обмена.

## Адаптивность

Три версии, переключаются медиазапросами; все размеры — токены в `src/styles/global.css`.

| Ширина | Версия |
|---|---|
| до 1023 px | мобильная (макет 320), колонка не шире 640 px |
| 1024–1439 px | лаптоп — промежуточные размеры |
| от 1440 px | десктоп (макет 1440); главное фото не растягивается шире макета |

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run deploy   # сборка и публикация на GitHub Pages (ветка gh-pages)
```

Сайт открывается из подпапки `/Samolet_project/` — это `base` в `vite.config.js`.
Картинки из `public/` подключаются через `import.meta.env.BASE_URL`.

## Структура

```
src/
  main.jsx, App.jsx
  styles/global.css          # цвета, шрифты, размеры трёх версий (токены из UI Kit)
  data/
    questions.js             # вопросы по категориям
    content.js               # тексты страницы, меню, соцсети
  hooks/useGame.js           # состояние игры (колода, индекс, уже показанные)
  utils/                     # shuffle, deck (раздача), share, cx
  api/sendFeedback.js        # отправка формы (адрес в .env, без него — демо-режим)
  components/
    Header/ (Header, Logo)   Hero/   TextSection/   FeatheredPhoto/
    Game/ (Game, Card, CategoryTabs)
    FeedbackForm/   Footer/   SocialLinks/   Button/   Icons/
public/
  images/                    # фото страницы и обложки колод
```

У каждого компонента свой `*.module.css` (CSS Modules).
